# Home 快捷面板设计

## 目标

在《灵兽江湖》内提供可随时呼出的工具面板，用 Home 键切换显示。面板集中呈现 SL 状态与常用功能，减少记忆快捷键和配置项的成本；视觉上采用深色玻璃、细边框和低饱和青金点缀，避免遮挡战斗与对话信息。

## 非目标

不改变存读档安全策略，不解除正式目录限制，不新增存档写入能力，不接入 FairyGUI，不自动部署正式插件。

## 方案比较

- IMGUI 悬浮面板：接入现有 `RuntimeDriver.OnGUI()`，无额外依赖，错误边界清晰；视觉上限低于原生 UI，但足够做卡片、状态灯和按钮层次。已选定。
- FairyGUI 原生面板：视觉融合最好，但需处理游戏 UI 生命周期、焦点与层级，改动和回归风险更高。
- 快捷条：实现最小，但状态与后续功能扩展性不足。

## 设计

- Home 键在应用聚焦时切换面板；输入框聚焦时不拦截，避免打字冲突。
- 面板宽度按分辨率限制，位于屏幕左侧约 6% 处，垂直居中；小屏幕自动收窄。
- 顶部为标题、版本和状态灯：隔离可用 / 正式受限 / 插件异常。
- 状态区显示模式、对话前检查点、当前读取目标与不可操作原因；不读取敏感内容。
- 操作区提供快速保存、读取检查点、对话中选择对话前检查点；操作仍完全复用 `SavePressed()` / `LoadPressed()`，不在面板层绕过安全检查。
- 辅助区显示判定预览开关，可点击切换；下方列出当前 F5/F6/Home 按键。
- 视觉基调：半透明近黑蓝、细冷色描边、青绿状态灯、卡片分层和清晰禁用态。

## 验收

- Home 打开/关闭状态可测试。
- 输入框聚焦时 Home 不触发。
- 按钮可用性与状态文案可测试。
- 面板操作只调用既有安全入口。
- 现有测试与 Release 构建通过。
